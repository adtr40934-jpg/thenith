# Thenith Dashboard (DASH) — المنظومة الإدارية وبرمجة الكروت الذكية

> لوحة التحكم المتكاملة لمنصة **Thenith** لإدارة المستخدمين، الاشتراكات، المتجر، وسجلات الأمان، بالإضافة إلى **محطة إدارة وبرمجة الكروت الذكية (Smart Cards & NFC Studio)**.

---

## 🚀 محتويات المشروع (Project Structure)

```
DASH/
├── back/                      # خادم الواجهة الخلفية (Node.js + Express + MongoDB)
│   ├── src/
│   │   ├── config/            # إعدادات البيئة وقاعدة البيانات
│   │   ├── controller/        # المتحكمات الإدارية (كروت، مستخدمين، متجر، اشتراكات)
│   │   ├── middleware/        # المصادقة والحماية ومعدل الطلبات
│   │   ├── models/            # نماذج Mongoose (PhysicalCard, NfcSecurity, User, etc.)
│   │   ├── routes/            # مسارات الـ API المحمية
│   │   └── services/nfc/      # محركات تشفير وبرمجة شرائح NFC (NTAG213, NTAG215, NTAG216)
│   └── docs/
│       └── api.md             # التوثيق الشامل لمسارات الـ API ونماذج الاستجابة
│
└── front/                     # واجهة المستخدم الإدارية (React 19 + Vite + TailwindCSS)
    ├── src/
    │   ├── api/               # إعداد Axios و Interceptors
    │   ├── components/        # المكونات العامة والهيكل الإداري
    │   ├── hooks/             # خطافات التفاعل (Web NFC, الإشعارات)
    │   ├── pages/             # الصفحات الإدارية ولوحة التحكم
    │   └── services/          # خدمات الربط مع الـ API وإدارة طابور NFC
```

## 🛠️ متطلبات التشغيل (Prerequisites)

- **Node.js**: إصدار 18 أو أحدث (يُفضل LTS 20+)
- **MongoDB**: اتصال صالح بقاعدة البيانات المحلية أو السحابية (MongoDB Atlas)
- **متصفح داعم لـ Web NFC**: Google Chrome على هواتف Android لبرمجة الكروت فيزيائياً عبر التردد اللاسلكي، مع توفر وضع المحاكاة على أجهزة الكمبيوتر المكتبية.

## ⚡ خطوات التثبيت والتشغيل المحلي (Quick Start)

### 1. تشغيل الخادم الخلفي (Backend)

```bash
cd back
npm install
npm run dev
```
- المنفذ الافتراضي للباك إند: `http://localhost:4001` (أو المعين في `.env`).

### 2. تشغيل الواجهة الأمامية (Frontend)

```bash
cd front
npm install
npm run dev
```
- الرابط المحلي: `http://127.0.0.1:3001`

## 📱 منظومة إدارة وبرمجة الكروت الذكية (Thenith NFC Studio)

تم تطوير محطة متكاملة لإدارة الكروت الذكية والتكامل مع الـ API وبرمجة الشرائح:

1. **إدارة الكروت والبيانات (Cards Management)**:
   - إنشاء كروت فردية أو توليد دفعات إنتاج مجمعة (Bulk Generation).
   - توليد معرّف فريد داخلي `cardId` ومعرف عام `publicId` ورابط خاص `targetUrl`.
   - توليد كلمة مرور أمان سداسية مشفرة فريدة لكل كارت (`cardPassword`).

2. **برمجة وكتابة شريحة NFC بالهاتف (NFC Write & Lock)**:
   - بدء جلسة التكوين التلقائية عبر الـ API.
   - كتابة سجل الـ NDEF المعتمد برابط الكارت الفيزيائي بمجرد ملامسة الهاتف.
   - قفل الشريحة بكلمة المرور القادمة من الـ API لمنع التعديل غير المصرح به.
   - التحقق التلقائي وتسجيل العملية في سجلات النشاط والتدقيق الأمني.

3. **فحص وقراءة الكروت (NFC Read & Verify)**:
   - قراءة المعرف التسلسلي للبطاقة (UID) والسجلات المخزنة.
   - المطابقة الفورية بين الكارت الفيزيائي وسجل المنظومة في قاعدة البيانات.

4. **إعدادات ومطابقة الـ API المتقدمة (API Settings & Mapping)**:
   - إمكانية ضبط الـ Base URL والمسارات ومفاتيح التوثيق (Bearer / API Key).
   - مطابقة الحقول المرنة (Field Mapping) دون الحاجة لتعديل الكود المصدري.
   - طابور معالجة الكروت وسجل تاريخي مشفر وخالٍ من كلمات المرور المكشوفة.
